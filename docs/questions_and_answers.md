# 学习问答整理

这里整理学习过程中提出过的知识性问题，便于复习和面试表达。

## `if args.question: run(...); return`是什么意思

如果命令行直接提供问题，就运行一次并通过`return`结束`main()`；没有提供问题时才进入后面的交互循环。删除`return`会导致单次任务结束后继续进入交互模式。

## `action="store_true"`是什么意思

这是`argparse`的布尔开关：命令中出现该选项时保存`True`，未出现时为`False`。

```text
未写--no-trace → args.no_trace=False
写了--no-trace → args.no_trace=True
```

## `strip()`是什么意思

删除字符串开头和结尾的空格、换行和制表符，不删除中间空格。它能把只输入空格的内容变成空字符串，也方便识别带空格的`q`退出命令。

## 为什么大文本块精度可能更低

“包含更多信息”不等于“更容易准确匹配”。多个主题被压缩到一个向量后，局部语义会被稀释；过长文本还可能被模型截断。与此同时，大块也确实会降低计算效率、增加Token和噪声。

## 工具注册表是什么意思

工具注册表集中管理允许调用的工具、参数校验和真实函数映射。它不是数据库或Windows注册表，而是Agent的执行白名单。

```text
"calculator" → calculate()
"search_knowledge_base" → KnowledgeBase.search()
未知工具 → 拒绝
```

## “不使用eval”是什么意思

`eval()`会把字符串作为Python代码执行。若参数来自用户或模型，攻击者可能读取文件或执行系统命令。项目使用AST解析和运算符白名单，只允许数字与基础数学运算。

## Agent控制循环怎样运行

每一轮把`messages`和工具Schema发给模型。模型有工具调用时，程序执行并追加`tool`消息；没有工具调用且存在答案时结束。最大步数、重复调用检测和未知工具白名单负责限制风险。

## 为什么工具结果要返回模型

模型只知道自己申请了工具，并不知道真实执行结果。把结果作为`role=tool`消息返回后，模型才能继续计算、选择其他工具或形成最终答案。

## 测试为什么不调用真实API

测试使用`FakeCompletions`预设模型第一轮调用工具、第二轮返回答案。这样可以稳定验证控制器、工具结果和`tool_call_id`，速度快、不花费API额度，也不受模型随机性和网络影响。

## RAG和Agent是什么关系

RAG负责检索知识证据；Agent负责判断何时调用RAG、是否需要其他工具，以及何时结束。RAG通常是Agent工具箱中的一个只读工具。
