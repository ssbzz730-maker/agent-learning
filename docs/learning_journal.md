## 重要概念检查

### 分块为什么需要重叠

固定边界可能把一句完整规定切开。重叠能保留跨边界语义，但重叠过大会增加重复数据、索引体积和检索噪声。曾使用过“块大小 160、重叠 40”来理解这一权衡，它不是适合所有文档的固定标准。

### 大文本块为什么可能降低精度

大块包含更多信息，也会提高 Token、延迟和计算成本；但精度问题更关键：多个主题通常被压缩成一个向量，当前问题对应的局部语义可能被稀释，过长内容还可能被模型截断。

### Embedding 与 Reranker 的区别

- Embedding 将问题和文档分别编码，候选向量可以预先保存，速度快，适合大规模召回。
- Reranker 同时阅读问题和候选文档，交互更充分，通常更准确，但计算更慢。

它们不只是简单的“低精度模型”和“高精度模型”，而是承担不同阶段的任务。

### BM25、向量检索与 RRF

- BM25 擅长编号、错误码、姓名和精确词语。
- 向量检索擅长同义表达和语义相似。
- 两种分数的尺度不同，RRF 使用排名而不是原始分数进行融合。

### 为什么检索使用独立问题

“取消呢？”本身不能表达完整意图，需要结合历史改写成可独立理解的问题。检索使用独立问题提高召回准确性；生成阶段仍可以提供当前问题和必要历史，使回答保持对话自然。历史帮助理解意图，但不能充当知识库事实。

### 为什么无证据时要拒答

模型即使没有可靠证据也可能生成流畅答案。阈值过滤、来源约束、Prompt 限制和引用校验共同降低幻觉；如果知识库没有相关规定，应明确说明没有足够证据。

### Agent 为什么需要注册表

模型只能建议调用哪个工具，注册表决定该工具是否存在、参数是否合法、对应哪个真实函数。未知工具必须拒绝，不能把模型输出直接当成可执行代码。

### 为什么不能使用 `eval()`

`eval()` 会把字符串当作 Python 代码运行。如果字符串来自用户或模型，就可能执行任意代码。安全计算器只允许数字、括号和指定数学运算符。

## 学习过程中遇到的典型故障

### PyTorch 与 CUDA 组件版本不一致

现象：导入 `torch` 时缺少 `_cuda_endAllocateCurrentStreamToPool`。

理解：不是 RAG 代码错误，而是 Python 环境中的 PyTorch Python 包、二进制扩展或 CUDA 组件版本不匹配。后来使用项目独立 `.venv` 隔离环境。

### 分块结果为空导致 Chroma 拒绝写入

现象：

```text
准备写入 0 个文本块
Expected Embeddings to be non-empty ... got []
```

理解：真正的首要故障是读取或分块后得到空列表。程序应在调用 `collection.add()` 前检查文本块数量，并定位文件路径、编码、清洗或分块逻辑。

### 系统环境变量存在，但当前进程读取不到

理解：系统环境变量、用户环境变量和当前 PowerShell 进程变量作用域不同。已经打开的 VS Code 不一定自动读取后来新增的环境变量，需要重启应用或显式加载到 `$env:DEEPSEEK_API_KEY`。

### GitHub HTTPS 推送中断

经历的错误包括：

- `SEC_E_NO_CREDENTIALS`：受控进程无法取得 Windows HTTPS 凭据。
- `curl 52 Empty reply from server`：对象发送后，远程确认响应被网络中断。
- `Host key verification failed`：尚未确认 GitHub SSH 主机指纹。
- `Load key ... Permission denied`：当前进程无法读取私钥文件。
- `Permission denied (publickey)`：GitHub 没有接受所提供的公钥。

最终在 Windows 用户自己的 `.ssh` 目录生成密钥，向 GitHub 添加对应公钥，并通过 `ssh.github.com:443` 推送成功。

需要记住：

```text
Writing objects: 100%          ≠ 远程分支一定更新成功
[new branch] main -> main      = 远程分支创建成功
```

私钥、API Key、`.env` 和虚拟环境绝不能提交到 GitHub。

## 已问过的代码基础问题

- `os.getenv()`：从当前进程环境中读取变量；不存在时返回 `None` 或指定默认值。
- `action="store_true"`：命令行出现该开关时设置为 `True`，否则为 `False`。
- `strip()`：删除字符串首尾空格、换行和制表符，不删除中间空格。
- `if args.question: ... return`：提供命令行问题时只运行一次并结束，不进入交互循环。
- `reciprocal_rank_sum += 1`：累加倒数排名；答案排第 1 时贡献 `1/1=1`，排第 2 时贡献 `1/2`，最后除以问题数得到 MRR。
